# Code of Conduct

## Kraivor Community Standards

Kraivor is committed to building an open, respectful, and inclusive environment for developers, contributors, and the community.

By participating in this project, you agree to follow this Code of Conduct.

---

# Our Values

We encourage:

- Respectful communication
- Constructive feedback
- Collaboration and knowledge sharing
- Professional and inclusive behavior
- Helping developers grow together

We want Kraivor to be a welcoming space for everyone.

---

# Expected Behavior

Examples of positive behavior include:

- Being respectful and professional
- Accepting feedback gracefully
- Supporting new contributors
- Using inclusive language
- Focusing on what benefits the community
- Discussing ideas without personal attacks

---

# Unacceptable Behavior

The following behaviors are not tolerated:

- Harassment or discrimination of any kind
- Hate speech or abusive language
- Personal attacks or insults
- Trolling or intentionally disruptive behavior
- Sharing private information without permission
- Malicious code, security abuse, or exploit attempts
- Spam, phishing, or deceptive activity

---

# Security & Responsible Disclosure

If you discover a security vulnerability:

- Do NOT open a public issue
- Report it privately and responsibly
- Allow maintainers time to investigate and patch

Security-related abuse may result in immediate removal from the community.

---

# Contribution Guidelines

Contributors should:

- Follow the project architecture and coding standards
- Write clean, maintainable code
- Add tests where appropriate
- Keep pull requests focused and documented
- Respect code review feedback

---

# Enforcement

Project maintainers may:

- Remove harmful content
- Reject contributions
- Restrict participation
- Temporarily or permanently ban contributors

depending on the severity of violations.

---

# Reporting Issues

If you experience or witness unacceptable behavior, please contact the maintainers privately.

All reports will be reviewed fairly and handled professionally.

---

# License

By participating in Kraivor, you agree to follow this Code of Conduct to help maintain a healthy and productive open-source community.
