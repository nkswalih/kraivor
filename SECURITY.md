# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| latest (main) | ✅ |
| < main | ❌ |

## Reporting a Vulnerability

Email **security@kraivor.dev**. Do NOT file public GitHub issues.

You will receive an acknowledgment within **48 hours** and a detailed response within **7 days**.

## Disclosure Policy

- 90 days to patch before public disclosure
- CVE assignment upon confirmation
- Public acknowledgment of reporter (optional)
