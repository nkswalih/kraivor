## 🆘 Getting Help

1. **Check the docs** — many questions are answered in our documentation
2. **Search existing issues** — someone may have already asked
3. **Ask in Discussions** — the community is friendly and responsive
4. **Open an issue** — if you've found a bug or have a clear feature request
